# tic2practica1
 El objetivo de este proyecto es analizar las opciones universitarias que tengo y que valoro al acabar el bachillerato. Estas opciones son ingeniería aeroespacial, ingeniería civil e ingeniería.

## Estructura y apertura
- `index.html`: introducción y tarjetas.
- `opciones.html`: tabla comparativa e itinerarios.
- `salidas.html`: salidas profesionales y conclusión.
- `css/estilos.css`: estilos propios.
- `img/`: imágenes utilizadas.
- `evidencias/`: capturas de la página en funcionamiento.

Para acceder a la web se debe ejecutar `index.html`.

## Tecnologías
- HTML5: estructura y organización del contenido.
- CSS3: diseño y personalización visual.
- Bootstrap 5.3: tarjetas, menú, acordeones, carrusel y tablas.
